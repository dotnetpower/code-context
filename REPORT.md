# Performance report

The current public experiment is the
[AKS Store Demo CCTX on/off benchmark](docs/BENCHMARKS.md).
It includes fixed tasks, exact result-parity checks, all timed observations,
paired-session confidence intervals, and vector/raster figures.

Historical development notes previously kept here contained machine-specific
paths, unrelated local project names, and measurements against older cache
semantics. They have been removed from the current documentation rather than
republished as portable evidence. They are not the basis of the README's
performance claims.

Use the [backend reference](docs/REFERENCE.md) for current operation and the
[architecture document](DESIGN.md) for implementation design.

This cleanup changes current files, not previously published Git history or
release artifacts. Rewriting those requires a separate coordinated migration.
