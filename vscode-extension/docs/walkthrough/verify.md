# Ready to call is not the same as warm

The native self-test checks:

- the seven stable tool registrations;
- a native invocation through VS Code;
- the registered root and observational backend status.

It does **not** force a source-cache load. An `unloaded` index is normal
before your first lookup. Windows Agents can choose an existing Linux root.

Example status counters, not live telemetry:

```text
CCTX N S:12 C:1 P:0 E:0
```

Success, cache not ready, policy refusal, and input/system errors stay separate.
The walkthrough completes this check only after the self-test passes.
